# 🎨 FreeCodeCamp - Ejercicios de CSS

Este repositorio contiene las prácticas, talleres y proyectos de certificación correspondientes al módulo de **Diseño Web Responsivo (CSS)** del plan de estudios de [FreeCodeCamp](https://www.freecodecamp.org/).

El objetivo de este espacio es documentar el avance en hojas de estilo en cascada, diseño de interfaces y layouts modernos, sirviendo como evidencia técnica del proceso formativo.

## 🚀 Tecnologías y Conceptos Cubiertos

Durante el desarrollo de este repositorio se aplicarán los siguientes temas:
- **Fundamentos de CSS:** Selectores, especificidad, modelo de caja (Box Model), colores y tipografía.
- **Variables CSS:** Uso de *Custom Properties* para mantener temas y paletas consistentes.
- **Layouts Modernos:** Posicionamiento avanzado utilizando **Flexbox** y **CSS Grid**.
- **Diseño Responsivo:** Implementación de *Media Queries* para adaptar interfaces a múltiples dispositivos (Mobile First).
- **Animaciones:** Transiciones y transformaciones visuales fluidas.

## 📂 Arquitectura del Repositorio

Para mantener el código limpio, escalable y fácil de auditar, se utiliza un enfoque de **co-locación**. Cada mini-proyecto o taller tiene su propia carpeta dedicada donde el esqueleto estructural (`index.html`) y su hoja de estilos (`styles.css`) conviven lado a lado.

Ejemplo de la estructura esperada:

```text
.
├── Menu_Cafeteria/
│   ├── index.html
│   └── styles.css
├── Galeria_Fotos/
│   ├── index.html
│   └── styles.css
└── README.md
```

## 📝 Estrategia de Control de Versiones

El historial de Git está diseñado para ser modular y descriptivo. Cada `commit` representa un taller o mini-proyecto completado utilizando convenciones estándar (ej. `feat`, `refactor`, `chore`). Esto permite revisar la evolución visual y estructural de cada ejercicio de manera aislada y ordenada.
